# 插件目录资料

**Hello '84（你好 84）** 是面向 DeepSeek Harness 的独立悬浮挂件插件（不绑定主题，Shadow DOM 样式隔离）。在窗口角落养一台活着的 1984 Macintosh，内置多态像素屏保、InnerLife 自主琢磨与思绪气泡、双模 Mini DSH 副脑、复古命令行终端、翻页便签、软盘导出（Markdown + 复古长图 PNG）、复古闹钟、MacPaint Lite 与扫雷。

| 项目 | 内容 |
| --- | --- |
| npm 包 | [`dsh-hello84`](https://www.npmjs.com/package/dsh-hello84) |
| 分类 | `utility`（工具与挂件） |
| 图标 | [`icon.png`](../icon.png)，256 × 256 PNG |
| 许可证 | [MIT](../LICENSE) |
| 安装与开发 | [README](../README.md) |

## 提交到 awesome-dsh-plugin

将 [双语条目](xiaomao361__dsh-hello84.yml) 放入目录仓库的 `data/plugins/`，并确保 GitHub 仓库带有 `dsh-plugin` 主题标签。

## 预览素材

运行 `npm run preview` 生成的 `dist/preview.html` 内置模拟宿主 DSH 环境（含浅/深色宿主切换、状态模拟与 InnerLife 冒泡触发），可直接截屏并用于展示。
